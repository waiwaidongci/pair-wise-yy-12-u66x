# hxyfront-62011 马术蹄铁修整档案

源提示词编号：6

面向马术俱乐部蹄铁师的修蹄记录前端项目，已升级为**蹄位更换与复查准入闭环**：
可记录马匹编号、步态问题、蹄形评估、蹄铁类型、钉位、修蹄日期、下次复查日期和照片；
包含马匹蹄位列表、复查提醒、左右前后蹄对比、异常步态标记和蹄铁更换历史。

## 业务规则

- **唯一建档**：马匹编号（大小写/空格归一化）+ 蹄位（左前/右前/左后/右后）唯一。
- **开工沿用**：同一蹄位存在未结束修蹄（修蹄中）时，重复开工只沿用原任务，不新建。
- **保存准入**：步态问题、蹄形评估、钉位、下次复查日缺一项不得保存。
- **转复查**：勾选蹄裂 / 挫伤 / 明显跛行，保存后进入复查准入；无异常则直接闭环。
- **复查闭环**：须由**另一位蹄铁师**（与开工者不同）**连续两次确认稳定**，并**补齐蹄底照片**，才允许闭环；任一次"不稳定"都会使连续稳定计数清零。
- **闭环前换蹄铁**：复查未闭环时再次开工，旧任务结论标记为失效（superseded），结论不计入当前状态，但完整历史留档可查。

## 模块拆分

| 模块 | 目录 | 职责 |
| --- | --- | --- |
| 规则 | `src/rules/` | 类型、状态机、必填校验、开工沿用、复查准入、提醒/指标派生（纯函数） |
| 存储 | `src/storage/` | localStorage 持久化、演示种子数据、跨标签页同步的单一 store |
| 界面 | `src/ui/` | 蹄位列表、复查提醒、开工、修蹄表单、复查闭环、四蹄对比、历史时间线 |

列表、提醒、详情共享同一份 store 状态，每次变更统一持久化；刷新页面或多标签页打开均保持一致。
