# hxyfront-62011 蹄位更换与复查准入闭环

马术俱乐部蹄铁师工作台：在原「修蹄记录」基础上升级为**蹄位更换 → 记录保存 → 复查准入 → 闭环/换铁留档**的完整闭环。

## 业务规则

- **马匹编号 × 蹄位唯一**：同一编号 + 左前/右前/左后/右后蹄，同一时刻只允许一条未结束档案；重复开工自动沿用原任务，不产生新档案。
- **保存准入**：步态问题、蹄形评估、钉位、下次复查日四项缺一项不得保存（界面逐项标红提示）。
- **转复查**：勾选蹄裂、挫伤或明显跛行，保存后状态进入「待复查」。
- **闭环准入**（须同时满足）：
  1. 由**另一位蹄铁师**（≠ 开工蹄铁师）确认；
  2. **连续两次**确认稳定——同一确认人；任一次「不稳定」计数清零重来；
  3. 蹄底照片补齐。
- **闭环前换蹄铁**：旧档案标记「结论失效」，原复查结论/确认作废，但完整历史时间线留档；自动生成接替的新任务。
- 数据通过 localStorage 持久化，**列表、提醒、详情刷新后一致**，多标签页实时同步。

## 三业务模块

| 模块 | 路径 | 职责 |
| --- | --- | --- |
| 规则 | `src/business/rules/index.ts` | 类型字典、唯一性、四项校验、状态机、复查闭环准入、提醒/指标派生（纯函数） |
| 存储 | `src/business/storage/taskStore.ts` | localStorage 持久化、订阅发布、跨标签页 `storage` 同步、演示数据 |
| 界面 | `src/business/ui/`、`src/components/` | React 订阅 hook、照片压缩；开工面板、复查提醒、蹄位列表、任务详情 |

## 技术栈

React 19 + Vite 7 + TypeScript（strict）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62011。首次打开自动写入 4 个演示档案（正常闭环、蹄裂待复查、挫伤+跛行今日复查、闭环前换蹄铁留档），页面底部可重置。
